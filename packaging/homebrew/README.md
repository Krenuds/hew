# Hew Homebrew tap

[Hew](https://hew3d.com) is a free, open-source 3D modeler. This tap
installs the desktop app on macOS:

```sh
brew install --cask hew3d/tap/hew
```

That puts `Hew.app` in `/Applications` and links `hew-cli`, the scripting
and MCP client bundled with the app, onto your `PATH`.

Hew updates itself in place, the same as a copy from the
[download page](https://hew3d.com/download), so `brew upgrade` skips it
unless you run `brew upgrade --greedy`. `brew uninstall --zap --cask hew`
also removes the app's settings, caches, and recovery files. It never
touches your Library folder.

This repository is generated by the
[packaging workflow](https://github.com/hew3d/hew/blob/main/packaging/README.md)
in `hew3d/hew` on every release and is overwritten each time, so send
issues and changes there rather than here.
